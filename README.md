# GreenLoop

> **Transforming Waste into Value**

GreenLoop is a smart recycling platform designed to promote sustainable waste management through a reward-based recycling system. The platform encourages citizens to sort recyclable waste at home, rewards their efforts with redeemable points, and connects communities, recycling companies, and local authorities within a circular economy.

---

# About the Project

Cities like **Abidjan** generate thousands of tons of waste every day, much of which could be recycled instead of polluting the environment.

GreenLoop addresses this challenge by combining technology, citizen engagement, and incentive mechanisms to make recycling simple, accessible, and rewarding.

The platform allows users to:

- Sort recyclable waste at home
- Schedule and track weekly waste collection
- Earn points for every successful collection
- Redeem rewards such as mobile airtime, food vouchers, or partner discounts
- Monitor their environmental impact
- Contribute to cleaner and more sustainable cities

# Getting Started

Clone the repository

```bash
git clone https://github.com/yourusername/greenloop.git
```

Move into the project folder

```bash
cd greenloop
```

Install dependencies

```bash
npm install
```

Run the development server

```bash
npm run dev
```

Open your browser at:

```
http://localhost:3000
```
